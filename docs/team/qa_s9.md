# QA S9 — independent review of the S9 session (d67da7a..89e77b9)

Scope: copy/paste area, ground-item pickup, save rename + Load game, settings (confirm placement, auto-build
ghosts, palettes/UI scale, reduce motion), AudioManager + hook-ups, Codex panel.
Method: code read of the full diff, then a failing XCTest for every core bug (`Core/Tests/FactoryCoreTests/QAS9Tests.swift`)
before the fix; app bugs fixed surgically and checked with `tools/ios-typecheck/run.sh --app-only`.

Result: **15 findings**: 1 high, 7 medium (1 of them a design issue), 7 low. **14 fixed**. 1 remains as a design decision (S9-15), plus a few low-severity notes.
`swift test` reports 164 tests passing (9 new). Typecheck OK. `build.py --strict` OK (no UI strings changed).

## Checked and found OK

- Rotation maths (`(x, y) → (H − y − h, x)`, footprint swap, `rotated(4) == identity`, negative quarter turns); covered by `testRotatedBlueprintStaysInBoundsAndPastes`, which checks all 4 rotations for bounds, overlap and a complete paste.
- Copy rect with negative or reversed corners: `GameController.rect` normalises them. The scene rect uses `−maxY·S` for its bottom edge, which is correct.
- Paste origin centring is `(w−1)/2`. Natural obstacles are de-duplicated for multi-tile rocks. Loot that doesn't fit spills to the ground and is counted in stats.
- The rename metadata rewrite keeps the thumbnail, `isAutosave` becomes false, and the world payload is passed through after its CRC is checked.
- Audio formats: all 29 one-shot and loop WAVs are 44.1 kHz mono and the music is 16 kHz mono. Every player connects with its buffer's format, and a mismatching file is dropped, not scheduled. Nodes are attached and connected before `prepare`/`start`. Every `play()` is guarded by `ensureRunning`. There are no completion handlers, so nothing runs off the main thread. Observers use `queue: .main` with `assumeIsolated`. Interruption, background and configuration-change handling re-arms the players.
- Settings: `confirmPlacement` is decoded tolerantly. `autoBuildGhostsEnabled` is pushed by `applySettings` in `init` and on every settings change, and is not saved with the world, which is intended.
- Localization: every new UI string goes through literal keys, L() or LF(). `build.py --strict` reports OK (253 UI keys, 100 % ru).
