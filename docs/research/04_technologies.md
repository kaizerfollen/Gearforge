# 04 — Technologies (Gearforge base set)

Source: Factorio 1.1.110 `base/prototypes/technology.lua` (normal mode), generated by `docs/research/tools/gen_techs.py`.

## Column meanings

- **cost count** – number of research units. `count_formula` for leveled/infinite techs uses `L` = level being researched (Factorio formula syntax; `^` = power).
- **cards** – per-unit ingredients (letters: R=mechanics(red), G=motion(green), K=defense(black), B=reaction(blue), P=fabrication(purple), Y=systems(yellow), W=orbital(white)). Every listed card is consumed ×amount per unit.
- **time/unit** – seconds per unit for one lab at speed 1. Wall time = count × time / Σ(lab speed × (1 + lab speed bonus) × (1 + module speed bonus)).
- **total** – total cards consumed and total lab-seconds (count × time).
- **rocket?** – "yes" if the tech is in the prerequisite closure of `rocket_silo` (must exist in MVP).
- **phase** – MVP or later phase (tech gated to the phase of what it unlocks). Later-phase techs that are rocket prerequisites remain researchable in MVP but only unlock their MVP-relevant recipes (e.g. `railway` unlocks `rail` needed for fabrication cards; locomotives stay locked until the trains phase).
- Techs named `X_N` are levels of a series; level N requires level N−1 (and is listed as a prerequisite).

### Effect modifier glossary

| modifier | meaning |
|---|---|
| inserter-stack-size-bonus | adds N to the hand size of non-stack inserters (base 1 → max 3) |
| stack-inserter-capacity-bonus | adds N to the hand size of stack inserters (base 1 → max 12) |
| mining-drill-productivity-bonus | +X% mining productivity for all drills of the force (additive) |
| laboratory-speed | +X% lab research speed (additive) |
| character-inventory-slots-bonus | +N main inventory slots |
| worker-robot-speed | +X% robot speed (additive) |
| worker-robot-storage | +N robot cargo size |
| worker-robot-battery | +X% robot battery |
| train-braking-force-bonus | +X% train braking force |
| character-logistic-requests / trash-slots | enable personal logistics slots (robots phase) |
| ghost-time-to-live | ghosts of destroyed entities persist (seconds in ticks) – robots phase |
| maximum-following-robots-count | +N combat robots following the player |
| ammo-damage / gun-speed / turret-attack | combat phase damage & fire-rate modifiers (category in brackets) |
| artillery-range | +X% artillery range |
