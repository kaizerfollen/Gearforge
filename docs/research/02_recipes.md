# 02 — Recipes (Gearforge base set)

Source: Factorio 1.1.110 `base/prototypes/recipe.lua` (+ auto-generated barrel recipes from `data-updates.lua`), NORMAL difficulty values (expensive mode ignored). Generated by `docs/research/tools/gen_recipes.py`.

## Column meanings

- **time s** – `energy_required` in seconds at crafting speed 1. Real time = time / (machine crafting speed × (1 + speed bonuses)). Default 0.5 s when unspecified.
- **ingredients / results** – amounts per craft. Fluids are marked `(fluid)` (units). Probabilistic results: `@ p=` is the chance that the result is produced on each craft (amount is fixed when it is produced).
- **hand** – handcraftable by the character: category `crafting` AND no fluid ingredient/result. Note: the character can handcraft any `crafting` recipe even if a machine-only intermediate is required, as long as all its intermediates are themselves handcraftable (see 05_mechanics §Handcrafting).
- **prod** – productivity modules allowed (recipe is in the productivity-module limitation whitelist).
- **start** – enabled at game start (no tech needed). **unlocked by** – technology id(s) that unlock it.
- **phase** – see 01_items conventions.
